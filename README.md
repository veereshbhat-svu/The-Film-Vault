# The-Film-Vault
##Page 1
Home / Discovery Page
The landing experience — where users first arrive and browse films.

What to build
Hero banner with a featured/spotlight film of the week
Horizontally scrollable rows by genre (Action, Drama, Sci-Fi, etc.)
Top 10 rated films section with rankings
Search bar to look up films by title
Navigation header with logo and links to other pages


##Page 2
Film Detail Page
A dedicated page for a single film — the core "movie entry" experience.

What to build
Large backdrop/poster image with title and tagline overlay
Key info: release year, runtime, genres, director, language
Star rating display (e.g. 8.4 / 10) with vote count
Plot synopsis section
Cast list with actor name and role
User review/comment section (can be static or interactive)

##Page 3
Top Charts / Browse Page
A filterable list view for ranking and exploring the full catalogue.

What to build
Ranked table or card grid of top-rated films
Filter sidebar or dropdowns: genre, year range, rating
Sort controls: by rating, release year, or title (A–Z)
Each film row/card links through to its Film Detail Page
Pagination or "Load more" button for the list
